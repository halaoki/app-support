IPTCPhotoSender for the Press

カメラから無線で写真を受信し、IPTC メタデータ（写真説明）を付けて FTP で送稿するまでを、iPhone / iPad 1 台で完結できる報道・スポーツフォトグラファー向けアプリです。本ガイドは各タブの操作を順に説明します。

Photos タブ

送稿する写真を登録し、メタデータを付けて送信する中心のタブです。

Add Photos ／ ＋ ボタン
送信する写真をタブに登録するためのボタンです。登録写真が 0 枚のときは画面中央に「Add Photos」が表示されます。1 枚でも登録されると「Add Photos」は消え、以降は右上隅の「＋」ボタンから登録します。

Edit（左上隅）
タブ上の写真を選択して、選んだ写真の削除、テンプレートの適用、選択した写真だけの送信（選択送信）ができます。1 枚ずつの送信は、写真をタップして開く編集画面からも行えます。

…（右上隅）
タブ上にあるすべての写真へ同じテンプレートを一括で適用します。また、すべての写真を削除することもできます。

Receive（中央上）
カメラから送信される写真を受信します（内蔵サーバーの動作をオンにします）。

  • iPhone のテザリング（Personal Hotspot）機能を使って受信できます。
  • または、カメラ側で FTP 接続設定ファイルを作成しておけば、テザリングを使わずにカメラと直接接続して受信できます。Canon カメラ（対応機種）用の接続設定はサポートページから無料でダウンロードできます。
  • Nikon・Sony 用も後日用意します。

テンプレート選択ボタン（中央 Receive の下）
Receive で写真を受信する際、ここで選んだテンプレートが適用された状態で取り込まれます。（受信後も、Edit から何度でも別のテンプレートを適用し直せます。）

Embed IPTC & Send via FTP ボタン（下段タブの上）
写真に適用されているテンプレート（写真説明メタデータ）を最終確定し、FTP で送信を開始します。このボタンの上には、現在選択されている FTP 送信先が表示されています。

ボイスタグ（音声メモ）について
カメラで写真に録音した音声説明（ボイスタグ）は、写真とペアで受信されます。Photos・Sent どちらのタブでも、写真の編集画面で再生して内容を確認できます。送信時には写真に紐付けたまま、ペアで送稿先へ送られるので、音声での指示やメモを写真と一緒にそのまま届けられます。
送信中の画面ロックについて
・送信中に iPhone 本体をロック（スリープ）すると、送信は止まってしまいます。そのため、送信中は自動ロック（自動スリープ）が働かないようにしています。
・送信中の誤タッチを防ぐために、中央上部に「鍵アイコン」が表示されます。これをタップすると画面をソフトロックできます。ソフトロックでは送信は止まりません。 ポケットに入れても誤操作しません。
・ソフトロックの解除は、画面下部に現れるスワイプバーで行います。
・ソフトロック中は、画面中央で現在の送信状況（送信済み枚数・残り枚数など）を確認できます。

写真の編集画面

登録された写真のアイコンをタップすると、その写真の編集画面が開きます。

  • 虫眼鏡アイコン（写真の左下隅）：タップすると全画面表示になり、ズームして写真のピント・細部を確認できます。
  • 切り取りアイコン（写真の右下隅）：タップするとトリミング画面が開き、トリミングや傾き調整ができます。確定後も何度でも調整し直せ、さらに一度も触っていない最初の状態に戻すこともできます。
  • メタデータ：その下に表示されます。別のテンプレートの適用や、内容の編集ができます。
  • 最下段のボタン：この写真を 1 枚だけ送信／FTP ではなく共有（Share）する／メタデータをクリアする／この写真を削除する、に加えて、メタデータのコピー・ペーストができます。直前に編集した写真と同じメタデータを別の写真にも適用したいときに便利です。コピー＆ペーストしても、撮影日時と連番（{Seq}／{Jseq}）は各写真固有の値が保たれます（上書きされません）。連番は送信時に写真ごとに振られます。

Sent タブ

Photos タブで送信が完了した写真が、ここに移動します。再送できるほか、再送の際に写真説明をはじめとするメタデータを改めて編集することもできます。基本的に Photos タブの編集画面と同じことができます。

※ あくまでも「再送」なので、トリミングはできないようにしています。トリミングできてしまうと、再送ではなく新規写真の送信になってしまうためです。

Template タブ

Template Field（テンプレート項目）

まず下方へスクロールし、Template Field（全 20 項目）のうち、自分に必要な項目へ内容を入力します。

右側の Customize ボタンから、項目の編集画面を開けます。20 項目のうち、左のチェックで「普段表示する項目」を選べます。登録後にまず触ることのない固定の項目はチェックを外しておくと、普段は見えなくなってテンプレートがスッキリし、誤編集も防げます。項目の並び順もここで変更できます。

編集したテンプレートは、上へスクロールして Template 欄の Save ボタンから名前を付けて保存できます。テンプレートは 75 個まで登録できます。また、保存しているすべてのテンプレートを 1 つのファイルとして書き出し、バックアップしたり共有したりできます。

Sequence Variable（連番変数）

続き番号を振る変数を設定できます。使用・不使用はスイッチで切り替えられ、テンプレートのどの項目の中でも使用できます。

  • 半角数字で入れる場合は {Seq}、全角数字で入れる場合は {Jseq} を使います。
  • 続き番号の開始番号は自由に設定できます。下の Reset ボタンを押すと、開始番号にリセットされます。
  • この番号は写真の送信をかけた時に振られるため、実際に送信した写真にのみ適用されます。したがって飛び番号や欠番は出ず、送信枚数と完全に対応した番号になります。
  • Sent タブにある送信済みの写真を再送しても、この番号だけは変わりません。その写真固有の番号となります。

Code Replacements（コード置換）

Photo Mechanic などで使えるコード置換サービスを利用できます。コードはダウンロードして使えるのはもちろん、そのコードに自分で作ったコードを足して使うことが、アプリだけで完結してできます。自作のコードは共有・保存・並べ替えができます。

テンプレートに使うと、実際の写真へ適用するまではコード表示のままなので、変数のような使い方もでき、活用法はユーザーのアイデア次第で広がります。Photos タブや Sent タブで個別の写真に使う場合は、コードを入れた瞬間に変換されます。

コード変換の「挟み文字」は初期設定では = ですが、自分の使いやすい文字に変更できます。

Receive タブ

カメラから写真を受信するためのサーバー情報を設定するタブです。

  • Address：カメラ側で設定したものになります。テザリングでの接続では iPhone が自動で割り振ります。
  • Port：2121 が初期設定で固定されています。
  • Username・Password：ご自分の好きなものを設定してください（接続するカメラ側もこれに合わせます）。設定せず空欄のままでも運用できますが、セキュリティのため設定することをおすすめします。
  • Send RAW：カメラから受信したままの、まったく加工しない RAW の状態で送信するモードです。テストなどに便利に使えます。

More タブ

3 つのページがあります。

  1. FTP：写真の送信先（FTP）を設定します。設定は複数作成でき、写真によって送信先を切り替えられます。
  2. Log：アプリの挙動を記録しています。不具合が出たときに、原因究明の手がかりになります。
  3. Account：現在のサブスクリプションの状態など、ご自分の利用状況を確認できます。

An all-in-one wireless workflow for press and sports photographers: receive photos from your camera, add IPTC metadata (captions), and send them to your picture desk over FTP — all on a single iPhone or iPad. This guide walks through each tab in turn.

Photos Tab

The main tab, where you register the photos to file, add their metadata, and send them.

Add Photos / the "+" button
Buttons for registering the photos you want to send. When no photos are registered, "Add Photos" appears in the center of the screen. Once at least one photo is registered, "Add Photos" disappears and you add more using the "+" button in the top-right corner.

Edit (top-left)
Select photos in the tab to delete them, apply a template to them, or send only the selected photos (Send Selected). You can also send a single photo from the editing screen that opens when you tap a photo.

… (top-right)
Applies one template to all photos currently in the tab at once. You can also delete all photos here.

Receive (top-center)
Receives photos sent from your camera (turns the built-in server on).

  • You can receive over your iPhone's tethering (Personal Hotspot) feature.
  • Alternatively, if you create an FTP connection setting file on the camera, you can connect to the camera directly and receive without using tethering. Connection settings for Canon cameras (supported models) can be downloaded for free from the Support page.
  • Settings for Nikon and Sony will be added later.

Template selector (below Receive, center)
When you receive photos with Receive, they are imported with the template selected here already applied. (After receiving, you can re-apply a different template as many times as you like from Edit.)

Embed IPTC & Send via FTP button (above the bottom tab bar)
Finalizes the template (caption metadata) applied to your photos and starts sending over FTP. The FTP destination currently selected is shown just above this button.

About locking the screen while sending
・If you lock (put to sleep) the iPhone itself while sending, the transfer stops. For this reason, auto-lock (auto-sleep) is disabled while sending.
・To prevent accidental taps during a transfer, a lock icon appears at the top-center. Tap it to soft-lock the screen. A soft lock does NOT stop the transfer. You can put the phone in your pocket without triggering anything by mistake.
・To release the soft lock, use the swipe bar that appears at the bottom of the screen.
・While soft-locked, the current transfer status (photos sent, photos remaining, and so on) is shown in the center of the screen.

Photo editing screen

Tap a registered photo's thumbnail to open its editing screen.

  • Magnifier icon (bottom-left of the photo): Tap to view the photo full-screen, where you can zoom in to check focus and fine detail.
  • Crop icon (bottom-right of the photo): Tap to open the cropping screen for cropping and straightening. You can re-adjust as many times as you like even after confirming, and you can also revert to the untouched original.
  • Metadata: Shown below. You can apply a different template and edit the content.
  • Buttons at the bottom: Send this one photo / Share instead of FTP / Clear the metadata / Delete this photo, plus Copy and Paste metadata. Copy/Paste is handy when you want to apply the same metadata you just entered to another photo. Even when you copy and paste, the capture date/time and the sequence number ({Seq} / {Jseq}) keep each photo's own values (they are not overwritten). Sequence numbers are assigned per photo at the moment of sending.

Sent Tab

Photos that finished sending from the Photos tab move here. You can resend them, and you can re-edit the caption and other metadata before resending. In general you can do the same things as on the Photos editing screen.

Note: Because this is strictly a resend, cropping is disabled. If cropping were allowed, it would no longer be a resend but the sending of a new, different photo.

Template Tab

Template Fields

First, scroll down and enter content into the Template Fields (20 in total) that you need.

On the right, the Customize button opens the field editor. Using the checkboxes on the left, you choose which of the 20 fields are normally visible. Unchecking fixed fields you rarely touch after setup keeps them hidden — this makes the template tidier and helps prevent accidental edits. You can also change the field order here.

To save an edited template, scroll back up and use the Save button in the Template section to save it with a name. You can store up to 75 templates. You can also export all of your saved templates as a single file to back them up or share them.

Sequence Variable

Lets you set up an incrementing number. Turn it on or off with the switch; it can be used inside any template field.

  • Use {Seq} for half-width digits, or {Jseq} for full-width digits.
  • You can freely set the starting number. The Reset button below returns it to the start number.
  • This number is assigned at the moment you send the photos, so it is applied only to the photos you actually send. As a result there are no gaps or skipped numbers, and the numbering corresponds exactly to the number of photos sent.
  • If you resend a photo from the Sent tab, this number alone does not change — it stays the number unique to that photo.

Code Replacements

You can use the same code-replacement service available in tools like Photo Mechanic. You can of course download and use code files, and you can also add your own codes on top of them — entirely within the app. Your own codes can be shared, saved, and reordered.

When used in a template, a code stays shown as the code until it is applied to an actual photo, so it can also be used like a variable — the possibilities are up to your own ideas. When used on an individual photo in the Photos or Sent tab, a code is converted the moment you type it.

The delimiter that wraps a code defaults to =, but you can change it to whatever character is easiest for you.

Receive Tab

The tab for setting up the server information used to receive photos from your camera.

  • Address: This is what you set on the camera. For a tethering connection, the iPhone assigns it automatically.
  • Port: 2121 is fixed as the default.
  • Username / Password: Set these to whatever you like (and match them on the connecting camera). You can operate with them left blank, but we recommend setting them for security.
  • Send RAW: A mode that sends the photo exactly as received from the camera — the untouched RAW. Useful for testing and similar purposes.

More Tab

There are three pages:

  1. FTP: Set up your send destinations (FTP). You can create multiple configurations and switch the destination depending on the photo.
  2. Log: Records the app's activity. It gives you clues for tracking down the cause if something goes wrong.
  3. Account: Check your own status, such as the current subscription state.
