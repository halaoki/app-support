Put your camera connection setting files here.
ここにカメラの接続設定ファイルを置いてください。

Example / 例:
  canon_connection_setting.NIF   (Canon .NIF)

The download button on index.html points to:
  downloads/canon_connection_setting.NIF
If your file has a different name, either rename the file to match,
or edit the href in index.html.

index.html のダウンロードボタンは
  downloads/canon_connection_setting.NIF
を参照しています。ファイル名が異なる場合は、ファイル名を合わせるか、
index.html の href を書き換えてください。
