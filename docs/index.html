Camera Connection Settings / カメラ接続設定

両アプリ共通でお使いいただけます。 / For use with both apps.

Canon

Canon カメラ用の接続設定ファイルです。この設定を対応機種にインストールすると、iPhoneのテザリングを使わずに、カメラとFTPで直接つないで画像を受信できます。
Connection setting file for Canon cameras. Install it on a supported body to connect by FTP directly — no iPhone tethering needed.

Download / ダウンロード

接続手順（日本語）

  1. ダウンロードした接続設定ファイルをカメラに取り込みます。EOS Utility で読み込むか、ファイルをメモリーカードの最上位階層（ルート）にコピーして、カメラのメニューから読み込みます。
  2. iPhone で現在接続している Wi-Fi の「自動接続（Auto-Join）」をオフにしておきます。これをしないと、カメラと接続してもすぐに切断され、自動接続の Wi-Fi に戻ってしまいます（カメラとの接続を優先させるため）。
  3. 取り込んだ接続設定をカメラに設定し、カメラ側で接続を開始します。
  4. iPhone の「設定 → Wi-Fi」を開き、一覧に IPTCPS が表示されたらタップして接続します。
  5. IPTCPS の左に接続中アイコン（ぐるぐる）が出たら（このとき Wi-Fi 一覧の最上部に表示されます）、右端の「ⓘ」をタップ →「IPv4アドレスを構成」を手動にして、IPアドレス：192.168.1.20／サブネットマスク：255.255.255.0 を入力します。あわせて、この画面で IPTCPS の「自動接続（Auto-Join）」をオンにします。
  6. アプリを開いて「Start」で接続を開始します。カメラの LAN ランプが点滅から点灯に変わります。
  7. カメラから送信を開始すると、アプリが写真を受信します。

How to connect (English)

  1. Load the downloaded setting file into your camera — via EOS Utility, or copy the file to the top (root) level of the memory card and import it from the camera menu.
  2. On iPhone, turn OFF “Auto-Join” for your current Wi-Fi network. Otherwise the iPhone quickly drops the camera connection and switches back to that network. (This gives the camera connection priority.)
  3. Select the imported connection setting on the camera and start the connection from the camera.
  4. On iPhone, open Settings → Wi-Fi. When IPTCPS appears, tap to connect.
  5. When the spinner appears next to IPTCPS (it moves to the top of the Wi-Fi list), tap the “ⓘ” on the right → set “Configure IP” to Manual, then enter IP Address 192.168.1.20 and Subnet Mask 255.255.255.0. While here, turn ON “Auto-Join” for IPTCPS.
  6. Open the app and tap “Start.” The camera’s LAN lamp changes from blinking to steady.
  7. Start sending from the camera, and the app will receive your photos.
⚠ セキュリティについて / Security note このダウンロード版の接続設定は、誰でもすぐに使えるよう、iPhone への接続（Wi-Fi）をパスワード無し、アプリのサーバー接続を anonymous（匿名）に設定しています。このままでも問題なく写真を送受信できますが、ダウンロード後は、できれば Wi-Fi とサーバーの両方にパスワードを設定してお使いください。設定は EOS Utility で行うと簡単です。

To let anyone use it right away, this downloadable setting leaves the iPhone Wi-Fi connection without a password and the app’s server login set to “anonymous.” It works fine as-is, but after downloading we recommend setting a password for both the Wi-Fi and the server. EOS Utility makes this easy.
