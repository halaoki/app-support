サポート & ダウンロード

ver3.3 (IPTCPhotoSender) / ver1.8 (FTPReceiver) よりカメラからの写真受信の操作が容易になりました。

基本、二つのアプリケーションでは iPhone / iPad の Personal HotSpot（インターネット共有）を利用してカメラと接続し、写真の受信を行います。これは設定・接続が簡単で、誰もが容易に接続できるためです。しかし実は、カメラ上で iPhone / iPad への接続設定を設定すれば、Personal HotSpot 機能を使用しなくても、カメラと iPhone / iPad を直接接続することが可能です。今までも直接接続は可能でしたが、今回の ver3.3 / ver1.8 により、直接接続は確実でとても簡単にできるようになりました。

下記にある「カメラ接続設定」を利用するか、ご自分で接続設定を作成し、カメラに設定してアプリの受信タブ（かんたん接続）にて受信設定し利用すると、スピード感が重要な取材中に、ストレス無く撮影した写真をカメラから iPhone / iPad に受け渡し・送信することができます。

カメラ接続設定

両アプリ共通でお使いいただけます。

Canon

Canon カメラ用の接続設定ファイルです。この設定を対応機種にインストールすると、iPhoneのテザリングを使わずに、カメラとFTPで直接つないで画像を受信できます。

ダウンロード

接続手順

  1. ダウンロードした接続設定ファイル（ファイル名：canon01.NIF）をカメラに取り込みます。EOS Utility で読み込むか、ファイルをメモリーカードの最上位階層（ルート）にコピーして、カメラのメニューから読み込みます。
  2. iPhone で現在接続している Wi-Fi の「自動接続（Auto-Join）」をオフにしておきます。これをしないと、カメラと接続してもすぐに切断され、自動接続の Wi-Fi に戻ってしまいます（カメラとの接続を優先させるため）。
    ※ IPTCPhotoSender ver3.3 / FTPReceiver v1.8 の「かんたん接続」オンで使用する場合は、現在接続している Wi-Fi の自動接続をオフにする必要はありません。カメラからの受信を終えてアプリの「受信」をオフ（FTPReceiver ではサーバー「停止」）にし、カメラの FTP 接続もオフにすれば、接続が切断され、カメラと接続する前に接続していた Wi-Fi に接続し直します。
  3. 取り込んだ接続設定をカメラに設定し、カメラ側で接続を開始します。
  4. iPhone の「設定 → Wi-Fi」を開き、一覧に IPTCPS が表示されたらタップして接続します。
  5. IPTCPS の左に接続中アイコン（ぐるぐる）が出たら（このとき Wi-Fi 一覧の最上部に表示されます）、右端の「ⓘ」をタップ →「IPv4アドレスを構成」を手動にして、IPアドレス：192.168.1.20／サブネットマスク：255.255.255.0 を入力します。あわせて、この画面で IPTCPS の「自動接続（Auto-Join）」をオンにします。
  6. アプリを開いて「Start」で接続を開始します。カメラの LAN ランプが点滅から点灯に変わります。
  7. カメラから送信を開始すると、アプリが写真を受信します。
⚠ セキュリティについて このダウンロード版の接続設定は、誰でもすぐに使えるよう、iPhone への接続（Wi-Fi）をパスワード無し、アプリのサーバー接続を anonymous（匿名）に設定しています。このままでも問題なく写真を送受信できますが、ダウンロード後は、できれば Wi-Fi とサーバーの両方にパスワードを設定してお使いください。設定は EOS Utility で行うと簡単です。

Support & Downloads

Receiving photos from your camera is now easier, starting with ver3.3 (IPTCPhotoSender) / ver1.8 (FTPReceiver).

By default, both apps connect to your camera using the iPhone / iPad Personal Hotspot (Internet Sharing) to receive photos, because it is simple to set up and anyone can connect easily. In fact, however, if you configure the connection to your iPhone / iPad on the camera itself, you can connect the camera and your iPhone / iPad directly — without using Personal Hotspot. Direct connection was always possible, but ver3.3 / ver1.8 now make it reliable and very easy.

Use the “Camera Connection Settings” below, or create your own connection profile and set it on the camera, then set it up on the app’s Receive tab (Quick Connect). You can then hand off and send the photos you shoot from the camera to your iPhone / iPad smoothly — without stress — during fast-paced assignments where speed matters.

Camera Connection Settings

For use with both apps.

Canon

Connection setting file for Canon cameras. Install it on a supported body to connect by FTP directly — no iPhone tethering needed.

Download

How to connect

  1. Load the downloaded setting file (File name: canon01.NIF) into your camera — via EOS Utility, or copy the file to the top (root) level of the memory card and import it from the camera menu.
  2. On iPhone, turn OFF “Auto-Join” for your current Wi-Fi network. Otherwise the iPhone quickly drops the camera connection and switches back to that network. (This gives the camera connection priority.)
    Note: When using Quick Connect (on) in IPTCPhotoSender ver3.3 / FTPReceiver v1.8, you do not need to turn off Auto-Join for your current Wi-Fi. After you finish receiving, turn the app’s “Receive” off (in FTPReceiver, “Stop” the server) and also turn off the camera’s FTP connection; the connection is then dropped and your device reconnects to the Wi-Fi it was on before connecting to the camera.
  3. Select the imported connection setting on the camera and start the connection from the camera.
  4. On iPhone, open Settings → Wi-Fi. When IPTCPS appears, tap to connect.
  5. When the spinner appears next to IPTCPS (it moves to the top of the Wi-Fi list), tap the “ⓘ” on the right → set “Configure IP” to Manual, then enter IP Address 192.168.1.20 and Subnet Mask 255.255.255.0. While here, turn ON “Auto-Join” for IPTCPS.
  6. Open the app and tap “Start.” The camera’s LAN lamp changes from blinking to steady.
  7. Start sending from the camera, and the app will receive your photos.
⚠ Security note To let anyone use it right away, this downloadable setting leaves the iPhone Wi-Fi connection without a password and the app’s server login set to “anonymous.” It works fine as-is, but after downloading we recommend setting a password for both the Wi-Fi and the server. EOS Utility makes this easy.

Supported: EOS-1D X Mark III, R1, R3, R5, R5 Mark II, R5 C

Per impostazione predefinita, entrambe le app si collegano alla fotocamera tramite l'Hotspot personale (Rete condivisa) dell'iPhone / iPad per ricevere le foto, perché è semplice da configurare e chiunque può collegarsi facilmente. In realtà, però, se configuri sulla fotocamera stessa la connessione verso l'iPhone / iPad, puoi collegare la fotocamera e l'iPhone / iPad direttamente, senza usare l'Hotspot personale. La connessione diretta è sempre stata possibile, ma la ver3.3 / ver1.8 la rende ora affidabile e molto semplice.

Usa le “Impostazioni di connessione della fotocamera” qui sotto, oppure crea il tuo profilo di connessione e impostalo sulla fotocamera, poi configuralo nella scheda “Ricezione” dell'app (Connessione rapida). Potrai così trasferire e inviare le foto scattate dalla fotocamera all'iPhone / iPad in modo fluido e senza stress, durante i servizi a ritmo serrato in cui la velocità è fondamentale.

Impostazioni di connessione della fotocamera

Utilizzabili con entrambe le app.

Canon

File di impostazioni di connessione per le fotocamere Canon. Installalo su un corpo macchina compatibile per collegarti via FTP direttamente, senza tethering dell'iPhone.

Scarica

Come connettersi

  1. Carica nella fotocamera il file di impostazioni scaricato (nome file: canon01.NIF), tramite EOS Utility, oppure copia il file nel livello principale (root) della scheda di memoria e importalo dal menu della fotocamera.
  2. Sull'iPhone, disattiva (OFF) “Accesso automatico” (Auto-Join) per la rete Wi-Fi attualmente connessa. In caso contrario l'iPhone interrompe rapidamente la connessione con la fotocamera e torna a quella rete. (In questo modo la connessione con la fotocamera ha la priorità.)
    Nota: se usi la “Connessione rapida” (attiva) in IPTCPhotoSender ver3.3 / FTPReceiver v1.8, non è necessario disattivare l'Accesso automatico della rete Wi-Fi attuale. Al termine della ricezione, disattiva la “Ricezione” nell'app (in FTPReceiver, “Arresta” il server) e disattiva anche la connessione FTP della fotocamera: la connessione verrà interrotta e il dispositivo si ricollegherà alla rete Wi-Fi a cui era connesso prima di collegarsi alla fotocamera.
  3. Seleziona sulla fotocamera l'impostazione di connessione importata e avvia la connessione dalla fotocamera.
  4. Sull'iPhone, apri Impostazioni → Wi-Fi. Quando compare IPTCPS, toccalo per connetterti.
  5. Quando accanto a IPTCPS compare l'indicatore di caricamento (in questo momento si sposta in cima all'elenco Wi-Fi), tocca la “ⓘ” a destra → imposta “Configura IP” su Manuale, quindi inserisci Indirizzo IP 192.168.1.20 e Maschera di sottorete 255.255.255.0. Da qui, attiva (ON) anche l'“Accesso automatico” (Auto-Join) per IPTCPS.
  6. Apri l'app e tocca “Start” per avviare la connessione. La spia LAN della fotocamera passa da lampeggiante a fissa.
  7. Avvia l'invio dalla fotocamera e l'app riceverà le tue foto.
⚠ Nota sulla sicurezza Per consentire a chiunque di usarlo subito, questa impostazione scaricabile lascia la connessione Wi-Fi all'iPhone senza password e l'accesso al server dell'app impostato su “anonymous” (anonimo). Funziona senza problemi così com'è, ma dopo il download consigliamo di impostare una password sia per il Wi-Fi sia per il server. Con EOS Utility è semplice.

Compatibilità: EOS-1D X Mark III, R1, R3, R5, R5 Mark II, R5 C

Soporte y descargas

Desde la ver3.3 (IPTCPhotoSender) / ver1.8 (FTPReceiver), recibir las fotos desde la cámara es más fácil.

De forma predeterminada, ambas apps se conectan a la cámara mediante la función Compartir Internet (Hotspot personal) del iPhone / iPad para recibir las fotos, porque es sencillo de configurar y cualquiera puede conectarse con facilidad. Sin embargo, si configuras en la propia cámara la conexión hacia el iPhone / iPad, puedes conectar la cámara y el iPhone / iPad directamente, sin usar Compartir Internet. La conexión directa siempre fue posible, pero la ver3.3 / ver1.8 ahora la hace fiable y muy fácil.

Usa los “Ajustes de conexión de la cámara” de abajo, o crea tu propio perfil de conexión y configúralo en la cámara; luego ajústalo en la pestaña “Recepción” de la app (Conexión rápida). Así podrás pasar y enviar las fotos que tomas desde la cámara al iPhone / iPad con fluidez y sin estrés, durante coberturas de ritmo rápido en las que la velocidad es clave.

Ajustes de conexión de la cámara

Para usar con ambas apps.

Canon

Archivo de ajustes de conexión para cámaras Canon. Instálalo en un cuerpo compatible para conectar por FTP directamente, sin necesidad de compartir conexión del iPhone.

Descargar

Cómo conectar

  1. Carga en la cámara el archivo de ajustes descargado (nombre: canon01.NIF), mediante EOS Utility, o copia el archivo al nivel superior (raíz) de la tarjeta de memoria e impórtalo desde el menú de la cámara.
  2. En el iPhone, desactiva (OFF) la “Conexión automática” (Auto-Join) de la red Wi-Fi a la que estás conectado. De lo contrario, el iPhone abandona rápidamente la conexión con la cámara y vuelve a esa red. (Así se da prioridad a la conexión con la cámara.)
    Nota: si usas la “Conexión rápida” (activada) en IPTCPhotoSender ver3.3 / FTPReceiver v1.8, no necesitas desactivar la Conexión automática de tu Wi-Fi actual. Cuando termines de recibir, desactiva “Recepción” en la app (en FTPReceiver, “Detén” el servidor) y desactiva también la conexión FTP de la cámara: la conexión se cerrará y el dispositivo volverá a conectarse a la red Wi-Fi en la que estaba antes de conectarse a la cámara.
  3. Selecciona en la cámara el ajuste de conexión importado e inicia la conexión desde la cámara.
  4. En el iPhone, abre Ajustes → Wi-Fi. Cuando aparezca IPTCPS, tócalo para conectarte.
  5. Cuando aparezca el indicador de carga junto a IPTCPS (en ese momento se coloca arriba del todo de la lista de Wi-Fi), toca la “ⓘ” de la derecha → pon “Configurar IP” en Manual e introduce la Dirección IP 192.168.1.20 y la Máscara de subred 255.255.255.0. Desde aquí, activa (ON) también la “Conexión automática” (Auto-Join) de IPTCPS.
  6. Abre la app y toca “Start” para iniciar la conexión. La luz LAN de la cámara pasa de parpadear a quedar fija.
  7. Inicia el envío desde la cámara y la app recibirá tus fotos.
⚠ Nota de seguridad Para que cualquiera pueda usarlo de inmediato, este ajuste descargable deja la conexión Wi-Fi del iPhone sin contraseña y el acceso al servidor de la app como “anonymous” (anónimo). Funciona bien así, pero después de descargarlo recomendamos poner una contraseña tanto para el Wi-Fi como para el servidor. Con EOS Utility es sencillo.

Compatibles: EOS-1D X Mark III, R1, R3, R5, R5 Mark II, R5 C

Los ajustes para Nikon y Sony estarán disponibles pronto.

지원 및 다운로드

ver3.3 (IPTCPhotoSender) / ver1.8 (FTPReceiver)부터 카메라에서 사진을 받는 조작이 쉬워졌습니다.

기본적으로 두 앱은 iPhone / iPad의 개인용 핫스팟(인터넷 공유)을 이용해 카메라와 연결하여 사진을 받습니다. 설정·연결이 간단하여 누구나 쉽게 연결할 수 있기 때문입니다. 하지만 사실 카메라에서 iPhone / iPad로의 연결 설정을 해 두면, 개인용 핫스팟 기능을 사용하지 않고도 카메라와 iPhone / iPad를 직접 연결할 수 있습니다. 지금까지도 직접 연결은 가능했지만, 이번 ver3.3 / ver1.8로 직접 연결이 확실하고 매우 간단해졌습니다.

아래의 “카메라 연결 설정”을 이용하거나, 직접 연결 설정을 만들어 카메라에 설정한 뒤 앱의 “수신” 탭(간편 연결)에서 수신 설정을 하여 사용하면, 속도가 중요한 취재 중에 스트레스 없이 촬영한 사진을 카메라에서 iPhone / iPad로 전달·전송할 수 있습니다.

카메라 연결 설정

두 앱 모두에서 사용할 수 있습니다.

Canon

Canon 카메라용 연결 설정 파일입니다. 이 설정을 지원 기종에 설치하면 iPhone 테더링을 사용하지 않고 카메라와 FTP로 직접 연결하여 이미지를 받을 수 있습니다.

다운로드

연결 방법

  1. 다운로드한 연결 설정 파일(파일명: canon01.NIF)을 카메라에 불러옵니다. EOS Utility로 읽어들이거나, 파일을 메모리 카드의 최상위(루트)에 복사한 뒤 카메라 메뉴에서 불러옵니다.
  2. iPhone에서 현재 연결 중인 Wi-Fi의 “자동 연결(Auto-Join)”을 끔(OFF)으로 해 둡니다. 그렇게 하지 않으면 카메라와 연결해도 금방 끊기고 자동 연결 Wi-Fi로 돌아가 버립니다(카메라 연결을 우선하기 위해).
    ※ IPTCPhotoSender ver3.3 / FTPReceiver v1.8의 “간편 연결”을 켜고 사용하는 경우에는 현재 연결 중인 Wi-Fi의 자동 연결을 끌 필요가 없습니다. 카메라에서 수신을 마친 뒤 앱의 “수신”을 끄고(FTPReceiver에서는 서버 “정지”), 카메라의 FTP 연결도 끄면 연결이 끊어지고, 카메라와 연결하기 전에 사용하던 Wi-Fi로 다시 연결됩니다.
  3. 불러온 연결 설정을 카메라에 지정하고, 카메라에서 연결을 시작합니다.
  4. iPhone의 “설정 → Wi-Fi”를 열고, 목록에 IPTCPS가 표시되면 탭하여 연결합니다.
  5. IPTCPS 왼쪽에 연결 중 아이콘(빙글빙글)이 나타나면(이때 Wi-Fi 목록 맨 위에 표시됩니다), 오른쪽 끝의 “ⓘ”를 탭 → “IP 구성”을 수동으로 하고, IP 주소: 192.168.1.20 / 서브넷 마스크: 255.255.255.0를 입력합니다. 이 화면에서 IPTCPS의 “자동 연결(Auto-Join)”도 켬(ON)으로 설정합니다.
  6. 앱을 열고 “Start”로 연결을 시작합니다. 카메라의 LAN 램프가 깜박임에서 켜짐으로 바뀝니다.
  7. 카메라에서 전송을 시작하면 앱이 사진을 받습니다.
⚠ 보안에 대하여 이 다운로드 버전의 연결 설정은 누구나 바로 사용할 수 있도록 iPhone 연결(Wi-Fi)을 비밀번호 없음, 앱의 서버 접속을 anonymous(익명)로 설정해 두었습니다. 이대로도 문제없이 사진을 주고받을 수 있지만, 다운로드 후에는 가능하면 Wi-Fi와 서버 양쪽 모두에 비밀번호를 설정하여 사용하시기 바랍니다. 설정은 EOS Utility로 하면 간단합니다.
